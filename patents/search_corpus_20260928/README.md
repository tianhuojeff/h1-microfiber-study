# H1 专利检索母集：受限的首轮公开检索记录

执行日：2026-09-28（Asia/Shanghai）  
执行人：本项目当前检索任务  
范围：洗衣/洗衣机与微纤维、微纤维英式拼写或微塑料的**题名字段**交集。目的只是形成可复跑的候选入口，补足此前“只有网页搜索线索、无数据库命中数”的缺口。

## 数据库与可复现输入

- 数据库：Google Patents 公开检索接口（网页入口与接口均公开可访问）。它聚合多局公开文献，原始公开文本仍须逐件回到相应公开页/PDF核验；本轮不把它称为任何专利局的法律状态或案卷来源。
- 检索输入（原样）：

```text
TI=((laundry OR "washing machine") (microfiber OR microfibre OR microplastic))
```

- 可复跑地址（将输入作为 `q` 参数）：  
  `https://patents.google.com/xhr/query?url=q%3DTI%253D%2528%2528laundry%2520OR%2520%2522washing%2520machine%2522%2529%2520%2528microfiber%2520OR%2520microfibre%2520OR%2520microplastic%2529%2529`
- 语法含义按接口字段名记录：`TI` 是题名限定；括号内两组词是对象限定。没有地域、申请人、CPC、公开日或法律状态过滤。检索入口会随数据库更新改变结果，复跑时必须另存原始响应并记录重跑时刻。

## 实际运行结果与可导出性

首次成功 API 响应为 HTTP 200；JSON 的 `results.total_num_results=98`（结果页按页返回，页数字段未在本轮成功响应的留存摘录中记录）。该 `98` 是本次窄题名检索的服务端即时计数，不是同族数、去重后数量，也不是相关专利数量。

紧接着为保存原始分页命中再次请求时，Google 返回 `GoogleSorry`（自动化查询限流）。因此本目录**没有伪造的 98 行命中表，也没有 CSV 导出文件**；`raw_export_status.json` 明确保留此次可导出性失败。此限制意味着这一轮只闭合了“正式公开数据库 + 明确检索式 + 可读命中计数”，尚未闭合“可审计原始母表”。

## 去重和纳入边界

1. 在有原始分页导出之前，不做申请号或同族去重，也不向既有 `14` 同族人工矩阵新增记录。
2. 后续恢复导出后，先保留原始记录，再按公开编号精确去重；同族归并只能采用来源页面明确给出的同族键或可回读的优先权链，并保留公开国别与版本。
3. 题名命中可包含纤维材料、洗衣方法等误命中；必须逐件通过摘要、权利要求和原始公开文本判定，不能因命中数、词频或未命中而推出技术空白、可专利性、侵权、有效性或自由实施结论。

## 下一轮的最小补口

在限流解除后，用同一 URL 分页保存原始 JSON/CSV、响应哈希、每页条数和下载时刻；再运行独立的摘要/权利要求功能词分支（过滤、反冲洗/再生、收集/移出），并记录每轮差集。只有该原始层保存成功，才可称为本检索范围内的“候选母表”。
