# 培训方法核验与本次技术比较建议（R4 子项）

## 结论及适用范围

本次研究的对象是 **14 个定向选择的专利同族**，目标是比较其对洗衣微纤维截留物的清理、转移、排液和移出路径；它不是完整检索母集，也尚未完成逐件状态核验和统一编码。因而当前可交付的方法主体应是“可追溯的人工功能—流程编码 + 由编码表派生的比较图表”。主题模型和网络分析可作为未来扩充母集、完成字段审计后的辅助工具，但不能替代专利原文的逐件编码，也不得把人工分类写成 LDA 结果。

## 2. 输入与预处理：保留原文、分层字段、可回溯规则

### 2.1 当前人工编码的输入

1. **文本层分开保存。**同族代表文本的标题、摘要、权利要求、说明书和版本不得混为一个“词袋”。权利要求用于其对应版本的请求保护特征；说明书用于披露路径。技术比较可同时使用两者，但不能把说明书实施方式写成某条权利要求的保护范围。
2. **字段层分开编码。**至少分开：清理动作、转移动作、收集对象、收集物含水量降低、腔体残液排空、液体排放/循环、移出对象、排液相对转移的先后、连接/密封和未知原因。这样才能避免把“可拆容器”“实际操作效果”“排水管路”混成同一标签。
3. **规则层保留前后证据。**课程把中文文本的分词列为首步：[16:43.5–16:54.3]“第一步……做分词”“中文分词”；并提示停用词：[23:32.6–23:34.5]“停用词”。本研究不必把人工编码伪装成自动分词；但若后续建立术语表，应保留同义词归并表、不得删除结构限定词，且每条归并要能回到原文。

### 2.2 若未来扩样后准备文本模型，才新增的预处理

课程在 [29:16.0–29:37.4] 明确把“清洗”“分词”及词典设计放进模型流程；146 [25:53.9–26:01.0]又提示主题数量由模型性能决定，并提到“主题一致性越高”。因此未来模型输入至少应记录：语料范围和日期、同族/版本去重、字段拼接规则、中文分词器与专业词典、英文规范化、停用词、同义词、未处理原文的哈希或定位。

这里的“同族去重、实体审计、版本分层”是本研究的数据治理要求，**不是**课程原话。

## 3. 方法选择条件：主题模型、网络图与人工编码各自的角色

### 3.1 主题模型（LDA 等）

课程证据：146 [13:21.0–13:28.0]称 LDA 为常用的概率模型；[18:50.8–19:02.8]说主题模型应按研究目标选，若更重解释性可选 LDA；[36:32.2–36:43.2]把“人工校验”列为流程一环；[39:54.0–40:06.8]提出要验证主题结果是否“合理”，[40:36.2–40:38.4]把更聚集的呈现解释为更稳定。可回看帧：`frames/146/01680.png`（28:00）、`frames/146/02400.png`（40:00）。

**建议（研究者推断，不冒称课程禁止小样本）：**

- 现阶段不运行 LDA/BERTopic 等。原因是 14 个定向同族不是为文本分布推断而来的母集，且编码和状态核验尚未闭合；模型即使运行，也只能生成候选词簇，不能修复样本选择偏差或代替原文阅读。
- 未来只有在真实补充检索形成可说明边界、完成同族与版本去重、语料字段和清洗规则冻结后，才把主题模型作为**探索性辅助**。应比较多个主题数/参数，报告一致性等指标并人工回读代表文本；将模型主题命名、代表文本和不稳定主题一并披露。
- 主题模型届时**能做**：从较完整、可复现语料中提出候选文本主题、辅助发现需回读的术语组合和代表文本。它**不能做**：证明技术效果、有效专利状态、行业空白、侵权/新颖性/创造性，或把“没有被模型分到某主题”写成专利未披露。

### 3.2 网络图

课程把节点和边定义为网络基础：[3:57.6–4:18.7]“节点”和“边”；并在专利场景举出三类不同语义：共同发明形成合作网络 [5:05.5–5:17.1]，同一专利中 IPC 同现形成技术共现网络 [5:44.8–6:11.1]，A 引证 B 构成有向网络 [7:10.7–7:34.0]。课程还强调网络为定量分析，需要指标 [9:40.0–10:02.1]；密度的定义为实际边数与最大可能边数之比 [18:24.8–18:33.2]，并提醒数值不能只摆出不解释 [28:02.0–28:09.3]。可回看帧：`frames/147/00480.png`（08:00）、`frames/147/02400.png`（40:00）、`frames/147/02640.png`（44:00）。

**建议（研究者推断）：**当前最多可做一个“小型编码共现展示”，前提是主表冻结且每条边都能回到同族原文；不宜据此报告“行业合作强弱”“技术布局中心”或社区/中心性结论。14 个定向同族中大量孤立点或稀疏边会使这些整体指标对样本边界高度敏感。

网络的节点和边必须预先写成下列其中一种，绝不可混用：

|网络名称|节点|边的严格定义|可解释为|不得解释为|
|---|---|---|---|---|
|共同申请人/共同发明人网络|已从本专利著录项核验的申请人或发明人实体|同一**代表同族**的同一著录项中共同出现；权重=共同出现的代表同族数|本样本中已核验的共同著录关系|把引证列表中的主体、相似名称或同集团主体当作合作；把合作说成技术相似或引用关系|
|IPC 共现网络|统一粒度的 IPC（例如小类或组）|同一代表文本的正式 IPC 字段中共同出现；权重=共同出现的代表同族数|该样本的分类共现|申请人合作、文献引用，或“必然技术融合”|
|专利引证网络|按统一规则去重的文献/同族代表|来源文本明确列出 A 引证 B 时，A→B；需保留引证来源和版本|本样本/已检索文献中的有向引证关系|共同申请、同一申请人或技术相似；不能把被引次数直接称为质量|
|人工功能共现图（若制作）|预先定义的功能代码，例如“先排液”“可拆容器”|同一代表同族被两项代码同时命中；权重=同族数|编码维度在这个定向样本中的共现|申请人合作、引证关系、因果链或完整技术谱系|

如要用 Gephi，课程的可复建要求可落实为节点表和边表：147 [37:08.0–37:13.2]“节点文件、边文件”；[40:07.1–40:09.2]说明边表要写“从谁指向谁”；[40:26.6–40:29.2]以合作 8 件举例权重为 8。故每张图应随附 `nodes`、`edges`、网络定义、筛选规则、脚本/手工生成规则和图例。

### 3.3 人工功能—流程编码（当前主方法）

**建议（研究者推断）：**这是现在唯一可直接承担核心结论的方法。它能：

1. 在同族与版本范围明确时，逐件比较结构、对象、动作和顺序；
2. 将“明确披露／推断／未找到／不适用／待核”分开；
3. 发现并修正把“没有实测”误作“没有披露”的编码错误；
4. 从已验收字段派生有限样本的描述性计数，并回读具体原文。

它不能：把人工标签叫作 LDA 主题、替代法律状态核验、估计行业比例或效果性能，也不能凭矩阵空白断言绝无技术方案。课程本身把模型结果之后的人工检查列入流程（146 [36:38.4–36:43.2]），可支持“算法输出仍需人工解释/验证”的做法；但课程没有说“14 篇/多少篇时禁止使用 LDA”，因此本报告不把该限制冒称为课程结论。

## 4. 验证与解释：结论必须回到原文和明示边界

1. **双人/复核编码。**先固定字段字典和纳入/排除例子；对冲突行保留两种判断、原文位置和裁决理由。重点复核“移出路径”“含水量降低”“腔体残液排空”三个不可互换字段。
2. **路径核验。**每项主要比较回到公开号、文本版本、权利要求号或说明书段落。披露结构/操作路径可以成为技术分析依据；没有实测只能限制“效果”结论，不能抹去已披露路径。
3. **图表核验。**由冻结主表重算，记录分母是“14 个定向同族”还是“有该字段可判文本的同族”；未知单列。143 [47:54.9–47:58.5]说相关性不等于因果，故任何共现、相关或时间并列不得写成某动作导致某性能。
4. **模型/网络核验（若未来使用）。**模型需交代清洗、参数、主题数、指标、代表文本和人工解释；网络需交代节点、边、方向、权重、孤立点和数据来源。147 [30:31.3–30:46.3]指出图上的热点名称是作者根据网络图总结的，故模块/簇的文字命名必须作为研究者解释，不能伪称软件自动给出事实。
