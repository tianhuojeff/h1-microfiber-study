3. 检查 PDF 文件头、可解析页数、首页题名与 DOI，计算 SHA-256。

6. 全文精读后才整理方法、样本、结果、边界和与 H1 的关系，再开展跨文献比较和研究方案讨论。

本批目录日期为 2026-09-21 工作归属日，下载记录保留真实发生时间与时区。第一批计划以约 10—12 篇有用全文为目标，数量不作为降低相关性要求的理由。

## 论文用途

- 直接证据：洗衣机外接或内置滤器、洗衣袋等措施的实测截留效果与使用条件。
- 维护与去向：滤材堵塞、压降、清理周期、再生废流、滤渣收集与用户维护行为。
- 测量方法：纤维计数和质量、材料鉴别、空白与对照、粒径/长度分布及物料衡算。
- 机制背景：旋流、气体流化和机械清理等；非洗衣场景的效果不能直接迁移为洗衣纤维去除率。
