# 回传与整合

复制 `return_template/`，以角色+日期命名自己的成果目录；不覆盖inputs或sources。提交原文件、可读图与复现说明，不只交截图。未做的项注明“未做+原因”，不要填示例结果冒充完成。

## 统一记录字段

|字段|含义|
|---|---|
|publication / family_id|具体公开版本和同族线索；同族不代替国别权利文本|
|structure_id / flow_id|`公开号:S01` / `公开号:F01`；首次分配后双方沿用，分支新增编号不重排|
|source_location / source_file / source_sha256|权利要求号、说明书段落/物理PDF页/图号，准确文件与哈希；没有定位不能标事实|
|claim_level|independent / dependent / description / interpretation；解释不混作原文|
|evidence_status|located / unresolved / conflict；未知不要强填否|
|raw_value / normalized_value / change_reason|清洗前值、派生值及可追溯改动理由|
|flow_medium / from_id / to_id|液/固/混合/未知；流路起终点与结构编号|
|destination_label|C受控 / D有证据排水 / A意外逸散 / U未知；不是根据结构猜测真实发生|
|assumption / unresolved / reviewer|设计假设、待解问题、责任人；数据未知与设计选项分开|

`record_template.json` 只有空字段，是格式示例，不能计入任何已完成记录。`deliverable_manifest.json` 填输出路径、版本/日期、输入版本、代码入口、依赖、执行命令、哈希和未完成项。结构/流路ID须由机械M1定好后给D3，冲突写issue，不自己重新编号。
