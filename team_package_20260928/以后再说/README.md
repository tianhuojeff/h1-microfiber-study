# H1 队友分工包

第一批目标：用现有14同族候选，把数据与结构证据变得可追溯、可复算、可设计对照。先各做约半天到一天的小交付，再一起决定扩检与原型；估算为有效工作小时，不是承诺工期。当前 `measurement_ready=false`，没有实测效果、专利创新或法律结论。

- `inputs/` 是本轮冻结输入副本；`return_template/` 是两位队友回传目录模板。`sources/` 保留源HTML及重点PDF。视频全文与画面索引在 `training_evidence/`；不把机器ASR当逐字引用。

统一键：`publication`（具体公开/授权版本）、`family_id`（数据库同族线索）、`structure_id`、`flow_id`。结构编号建议 `<publication>:S01`，流路 `<publication>:F01`；不得让两位队友各自重编号。同族不是权利范围，不能抹掉国别和版本差异。

大数据队友负责数据键、清洗规则、复算与可视化；机械队友负责原文结构/流路解释、制造与维护约束。技术字段发生分歧时，双方保留各自证据，由我们回原文仲裁；不以模型、漂亮图或CAD替代证据。

先问队友是否能用Python/Gephi、是否熟悉CAD/基础流体机械及可使用的实验条件；按实际能力挑第一批任务，不要求购买或立刻制造装置。
