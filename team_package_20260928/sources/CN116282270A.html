Abstract

本公开提供了一种去除洗衣机水中微塑料的方法、组件及洗衣机。用于解决现有技术中过滤洗衣水中的微塑料需要定期更换滤网，增加用户操作的复杂性以及发生额外费用的问题。其特征在于：在洗衣机上设置第一单元、第二单元和第三单元；第一单元用于处理洗衣机的漂洗污水，在第一单元的漂洗污水排出管路内设置微塑料过滤网，包括微塑料的固体杂质被截留在微塑料过滤网上；第二单元用于处理洗衣机的甩干污水；第二单元内的组件能够将甩干时洗衣机竖直方向的机械转动转换至水平方向并带动叶轮转动形成低压区，将污水吸入到中空套管内，同时对微塑料过滤网形成反冲洗；第三单元用于对已被增压的甩干污水进行旋流分离，使微塑料固体杂质进入收集腔中。

Description

一种去除洗衣机水中微塑料的方法、组件及洗衣机
技术领域：
本文公开的内容涉及环保领域，具体地说，涉及一种对洗衣机污水中微塑料的处理方法和设备。
背景技术：
由于人类对塑料制品的广泛使用，导致大量微塑料的产生，这些微塑料大多未经处理便被直接排放在自然环境中，对生态环境造成了较大危害。分散在工业和市政污水中的微塑料，引起人们对环境卫生污染物的严重关切，因为其既可作为污染物的来源，也可成为有毒和有害物质的载体，通过供水系统进入人体，对人类健康造成潜在威胁。据英国《卫报》报道，科学家分别在2022年3月和4月依次证实了人体血液和活人肺部中小粒径微塑料颗粒的存在。相关研究表明，微塑料进入人体后经过长期积累会产生生理毒性，导致神经组织损伤和生殖细胞受损等危害。而人们采用洗衣机洗涤衣物时产生的污水则是微塑料等固体污染物进入自然环境的主要来源之一。
目前，市面上对于洗衣机污水中微塑料的处理大多是通过过滤的方式。其中涉及到的相关专利，如ZL202121781201、ZL202120763894、ZL202020746811、ZL201920959024等。过滤方法可有效过滤掉洗衣机污水中的微塑料，然而，过滤装置在多次使用后将导致洗衣机污水通量降低、直至堵塞无法排出污水。因此，过滤方法需要定期更换滤网，增加操作的复杂性以及额外的费用。另外用户难以确定滤网的准确使用寿命，堵塞现象可能因为在多次使用后或者洗涤物的不同而随时发生，降低了用户的体验感。
发明内容：
为了解决背景技术中所提出的问题，本说明书提供了一种去除洗衣机水中微塑料的方法、组件及洗衣机并给出了具体实施例，通过具体实施例所给出的方案，说明如本申请获得应用后，能够在保证洗衣机经济性、高效性及用户体验性的同时，有效去除洗衣机污水中的微塑料，避免其直接向外界排放，有利于环境保护。
本说明书所公开的技术方案如下：
实施例1：首先给出一种去除洗衣机水中微塑料的方法，包括如下步骤：
在洗衣机上设置第一单元、第二单元和第三单元；
所述第一单元用于处理洗衣机的漂洗污水，在所述第一单元的漂洗污水排出管路内设置微塑料过滤网，从洗衣机内流出的漂洗污水首先通过过滤网，包括微塑料的固体杂质被截留在所述微塑料过滤网上，漂洗污水经所述漂洗污水排出管路的出口排出；
所述第二单元用于处理洗衣机的甩干污水；所述第二单元内的组件能够将甩干时洗衣机竖直方向的机械转动转换至水平方向并带动叶轮转动，通过所述叶轮的转动在中空套管内形成一个低压区，通过所述低压区将污水总管内的污水吸入到中空套管内，同时将所述第一单元中被截留在微塑料过滤网上的固体杂质吸出，对微塑料过滤网形成反冲洗；
所述第三单元用于对来自于所述第二单元中空套管内的带有固体杂质的已被增压的甩干污水进行旋流分离；所述第三单元设置有旋流分离器，能使沿着所述第二单元中空套管流出的流动介质通过切向入口进入所述旋流器中并形成高速旋转运动，在离心力的作用下，包括微塑料在内的固体杂质被甩向旋流器壁面并流向旋流器底流口，进入微塑料收集腔中。
实施例2、一种用于实现实施例1中所述方法的组件，包括带有电磁阀14的污水总管，其独特之处在于：
在所述污水总管上由电磁阀控制的出口段连接过滤净化出水管20，所述过滤净化出水管内置有微塑料过滤网；
所述组件还包括大锥齿轮9、小锥齿轮10、叶轮11以及中空套管13。
大锥齿轮9用于和洗衣机的减速离合器连接；大锥齿轮9与小锥齿轮10构成轴线交角为90度的锥齿轮传动，将洗衣机电动机水平方向的机械转动转换至竖直方向；小锥齿轮10与叶轮11同轴联接，由位于机械转轴一端的小锥齿轮带动机械转轴高速旋转，所述叶轮安装于机械转轴的另一端；叶轮11位于中空套管13内，所述叶轮转动后能在所述中空套管内形成低压区。
所述中空套管为U形弯管，所述U形弯管的第一直管段连接至过滤净化出水管20上，连接处位于所述微塑料过滤网的前端，以使得微塑料过滤网上的附着物能够在所述低压区的作用下被吸出。
实施例3，在实施例2的基础上得到优化后的本实施例：
所述组件还包括旋流净化出水管19以及水力旋流分离器5；
所述水力旋流分离器具有切向入口5-2、溢流口5-1、旋流腔5-3、锥段5-5、锥形挡筒5-7以及收集腔5-8；所述锥形挡筒位于收集腔内，且锥形挡筒的底部距离收集腔的内表面留有空隙，供包括微塑料的固体物质通过；
所述切向入口用于和所述U形弯管的第二直管段连接；
所述溢流口用于和所述旋流净化出水管连接；
所述锥形挡筒用于防止包括微塑料的固体物质回流；
所述收集腔用于收集包括微塑料的固体物质；
所述旋流净化出水管用于和洗衣机溢水管2连接。
进一步的，所述收集腔采用分体式螺纹连接结构，这样用户可以方便的自行清理。
实施例4、一种洗衣机，应用前述去除洗衣机水中微塑料的组件中的任一种。
以常规涡轮式全自动洗衣机为例进行设计。一种去除洗衣机水中微塑料的方法、装置及洗衣机主要通过两部分来获得净化水。第一部分用来处理漂洗污水，由洗涤内水管、污水总管、过滤净化出水管及过滤网等组成。其原理是：洗衣机漂洗污水首先由内水管流入污水总管，在重力的作用下，污水将通过过滤网，微塑料等固体杂质将被滤网所截留，通过过滤网的净化水则从过滤净化出水管排出。微塑料等固体杂质则被成功截留在过滤网上。
第二部分主要用来处理甩干污水以及经过第一部分过滤处理后截留在滤网上的微塑料等固体杂质。主要由大锥齿轮、小锥齿轮、轴承、机械转轴、叶轮、中空套管、旋流器及旋流净化出水管等组成。其中，大锥齿轮安装于洗衣机的带轮上，小锥齿轮与大锥齿轮啮合，当脱水时，在大锥齿轮的带动下，小锥齿轮高速旋转，通过两锥齿轮的连接可将洗衣机原本竖直方向的机械转动转换至水平方向。小锥齿轮上安装于机械转轴上并带动机械转轴高速旋转，机械转轴上安装有一对轴承起到支撑减小摩擦作用。机械转轴的一端安装有叶轮，并位于中空套管内。具体工作原理：当洗衣机脱水时，电动机提供动力，安装洗衣机带轮上的大锥齿轮带动小齿轮开始高速转动。同时与机械转轴相接的叶轮开始工作，在中空套管内形成一个低压区，将污水总管内的污水吸入到中空套管内，同时将漂洗过程中被截留在过滤网上的微塑料等固体杂质吸出，对滤网形成反冲洗效应。滤网上的微塑料等固体杂质随增压后的污水则沿着中空套管通过切向入口进入旋流器中，形成高速旋转运动，在离心力的作用下，密度大的微塑料等固体杂质则被甩向旋流器壁面附近并流向旋流器底流口经过锥形挡筒，进入微塑料收集腔中，实现微塑料等固体杂质与水的分离。其中锥形挡筒可防止进入收集腔的微塑料等固体杂质再次进入旋流器筒体，避免了其进入旋流器溢流口而从旋流净化出水管排出的风险
本说明书一个或多个实施例采用的上述至少一个技术方案能够达到以下
有益效果：
首先，利用洗衣机自身的机械动力对污水增压，无需额外的能耗，便可实现微塑料等固体杂质的去除；
其次，应用本方案后可以直接在现有洗衣机上进行改造，结构小巧紧凑，安装维护方便，可嵌入式安装于洗衣机，无需多余空间；
再次，利用洗衣机自身动力、通过设计叶轮的泵吸效应对过滤网实现自动反冲洗功能，解决了过滤装置堵塞或频繁更换滤网的不足；
此外，旋流器底流口的微塑料收集腔以螺纹式的设计结构拧装在洗衣机外壁，方便从洗衣机外部拆卸和定期对收集腔内的微塑料进行收集。
综上所述，本发明给出的方案，通过管路设计，并利用脱水甩干阶段洗衣机自身动力形成相关低压区，实现过滤模块的自动反冲洗，将过滤与旋流相结合，利用洗衣机自身动能，在无需额外能耗的条件下实现洗衣机污水中微塑料等固体杂质的高效去除，本申请获得应用后，能够在保证洗衣机经济性、高效性及用户体验性的同时，有效去除洗衣机污水中的微塑料，避免其直接向外界排放，有利于环境保护。

本发明设计的一种去除洗衣机水中微塑料的方法、装置及洗衣机主要通过两部分来获得净化水。第一部分是采用过滤模块来处理漂洗污水(包含前期多次漂洗的污水)，第二部分采用旋流分离模块来处理甩干污水以及经过第一部分过滤处理后截留在滤网上的微塑料等固体杂质。过滤模块依次由洗涤内水管3、污水总管17、过滤净化出水管20及过滤网18等构成，其中过滤网18安装于过滤净化出水管道20内。旋流分离模块依次由大锥齿轮9、小锥齿轮 10、轴承 12、机械转轴 8、叶轮 11、中空套管 13、旋流器5及旋流净化出水管19等组成。其中，大锥齿轮9同轴线安装于洗衣机的带轮4上，小锥齿轮10与大锥齿轮9啮合，当脱水时，在大锥齿轮9的带动下，小锥齿轮10高速旋转，通过两锥齿轮的连接可将洗衣机脱水过程中原本竖直方向的机械转动转换至水平方向。小锥齿轮10安装于机械转轴8上并带动机械转轴8高速旋转，机械转轴上安装有一对轴承12，起到支撑和减小摩擦作用。机械转轴8的一端安装有具备泵吸效果的叶轮11，叶轮11位于中空套管13内。中空套管13沿着叶轮11方向的顶端与旋流器5的切向入口5-2连接，形成甩干污水进入旋流器的通道。旋流器底流出口安装一个带有螺纹的微塑料收集腔5-8，收集腔5-8穿过洗衣机外壁1上对应的开孔，可使收集腔5-8能够方便从旋流器底流口拧松、取出，便于定期清理微塑料等固体杂质5-6。另外，旋流器底流出口处安装有位于收集腔内5-8的锥形挡筒5-7，可防止进入收集腔5-8的微塑料等固体杂质5-6再次进入旋流器筒体，避免了其进入旋流器溢流口5-1而从旋流净化出水管19排出的风险。
以常规涡轮式全自动洗衣机为例，第一部分过滤模块处理漂洗污水的原理是：洗衣机漂洗结束后，污水活塞开关21开启，漂洗过程产生的污水首先由洗涤内水管3流入污水总管 17，在重力的作用下，污水将通过过滤网 18，微塑料等固体杂质将被滤网18所截留，通过过滤网18的净化水则从过滤净化出水管20排出。微塑料等固体杂质则被成功截留在过滤网18上。
漂洗污水排放完毕后，电动机6开始转动，洗衣机进入脱水阶段，电动机通过传动带轮4将电动机6的动力传递到带轮一侧的减速离合器16上，以此实现脱水桶的高速旋转，以上为洗衣机原始自带的功能。在带轮4转动的过程中，此时固定安装于带轮4另一侧的大锥齿轮9也随带轮4开始转动，并通过与大锥齿轮9啮合的小锥齿轮10实现转速的改变(大、小锥齿轮的规格根据实际情况确定)，小锥齿轮10的高速转动将传递给与其同轴相连的机械转轴8，并驱动转轴8末端的叶轮11形成泵吸效应，具有泵吸效应的叶轮11在中空套管13内部形成低压区22，将污水总管17内的甩干污水吸入到中空套管13内，同时将漂洗过程中被截留在过滤网18上的微塑料等固体杂质5-6吸出，对滤网18形成反冲洗效应。
反冲洗获得的微塑料等固体杂质随增压后的污水沿着中空套管13通过切向入口5-2进入旋流器5中，形成高速旋转运动，在离心力的作用下，密度大的微塑料等固体杂质5-6则被甩向旋流器壁面附近并流向旋流器底流口经过锥形挡筒5-7进入微塑料收集腔5-8中，实现微塑料等固体杂质5-6与水的分离。获得的净化水5-4则从旋流器的溢流口5-1流出，最终从旋流净化出水管19排出。
整个微塑料等固体杂质的去除过程中可简要概括为：洗衣机甩干前漂洗污水是在自身重力的作用下通过过滤模块将微塑料等固体杂质截留在过滤网上；甩干污水则利用机械传动结构、叶轮11的泵吸效应，携带截留在滤网上的微塑料(反冲洗效应)进入旋流器5中进行离心分离，分离后的微塑料等固体杂质则进入到收集腔中被收集。
