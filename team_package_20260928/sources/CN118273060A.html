Abstract

一种用于过滤水的过滤器组件。该过滤器组件包括：i)壳体组，包括过滤室，该壳体组包括：‑壳体主体，沿着轴线延伸，壳体主体包括侧壁、底壁和入口开口，侧壁基本上平行于轴线，入口开口与底壁相对并且在周边上由开口边缘界定；‑盖装置，包括插塞构件和操作构件，插塞构件可插入到入口开口中，从而密封地接合所述开口边缘；ii)过滤器组，适于容纳在过滤室中，将过滤室分成脏区域和清洁区域，其中，过滤器组包括过滤介质和联接到过滤介质的过滤器结构，过滤器结构包括封头板。插塞构件具有贯通开口，并且封头板包括定心元件，使得操作构件可穿过贯通开口接合到定心元件，使得操作构件接合插塞构件并且使封头板与插塞构件密封接合。

Description

过滤器组件及洗衣机
技术领域
本发明涉及一种用于过滤水的过滤器组件。特别地，过滤器组件特别适于过滤离开洗衣机滚筒的水。另外，本发明涉及一种包括所述过滤器组件的洗衣机。
在现有技术中，已知过滤器组件解决方案，其适于过滤水，并且特别适于过滤离开洗衣机的洗衣机滚筒的水。
特别地，本发明涉及离开洗衣机滚筒的水的过滤，以过滤掉甚至包括微塑料在内的污染的且不需要的元素。
通常，所述微塑料的产生发生在织物的家用和/或工业洗涤操作期间，并且因此发生在织物产品(例如衣服)的家用和/或工业洗涤操作期间。更详细地，微塑料的产生发生在合成织物的洗涤操作期间，该合成织物是这样的织物，其全部或其一部分包括合成纤维，例如聚酯、聚丙烯、聚酰胺和/或丙烯酸。
更详细地，本发明聚焦于这样的洗衣机的洗涤水的过滤，在该洗衣机中执行合成织物的洗涤操作和/或至少部分地由天然纤维(例如棉或亚麻或羊毛)制成的织物的洗涤操作。
特别地，术语“洗衣机”也一般表示洗衣烘干机，即也具有干燥功能的洗衣机。
背景技术
在现有技术中，已知多种过滤器组件解决方案适于过滤水，特别是过滤掉微塑料，而且过滤掉其他类型的污染的或不需要的元素。类似地，现有技术中已知适于包括适于过滤离开洗衣机滚筒的水的过滤器组件的洗衣机。
已知的过滤器组件解决方案的常规问题涉及对水进行有效过滤的需要以及对具有简单且直观的维护操作的需要。
事实上，已经发现，有时，过滤器组件也由于其中包括的过滤器组的不正确定位而不具有有效的过滤。具体地，过滤器组在过滤器组件内的不正确定位导致无效的过滤作用，例如，通过呈现漏水且因此不能被有效过滤的区域。
以预定周期性执行维护操作的需要涉及可能的情况包括无效过滤和/或过滤器组定位误差和/或使用非原始过滤器组解决方案，其中不能确保充分的水过滤的情况。
具体地，每当必须对包括在过滤器组件中的过滤器组执行维护操作和/或更换操作时，包括在洗衣机中的过滤器组件可能配置这种不期望的情况。
特别是对于离开洗衣机滚筒的水的过滤，每当上述情况发生时，过滤器组需要检查或更换，这是因为过滤器组填充有由过滤器组捕获的微塑料和其他污染物，因此被阻塞或将要阻塞，。
发明内容
鉴于上述情况，强烈感觉到需要通过提供一种过滤器组件来解决这种问题，在该过滤器组件中，过滤器组的定位被简化，但最重要的是总是确定的。
因此，本发明的目的是提供一种满足这种需要的过滤器组件和包括这种过滤器组件的洗衣机。
特别是对于洗衣机，由于非专业用户必须执行这种需求，所以这种需求变得更加重要。
这种目的通过本文所述的过滤器组件来实现。类似地，这种目的通过本文所述的洗衣机来实现。
本文所述的用于过滤水的过滤器组件，优选地用于过滤从洗衣机的洗衣机滚筒出来的水，其中，所述过滤器组件能流体地连接到与所述洗衣机滚筒流体连接的洗衣机管道，其中，所述过滤器组件包括：i)壳体组，包括过滤室，所述壳体组包括：-壳体主体，沿着轴线延伸，所述壳体主体包括侧壁、底壁和入口开口，所述侧壁基本上平行于所述轴线，所述底壁优选地基本上正交于所述轴线，所述入口开口与所述底壁相对并且在周边上由开口边缘界定，其中，所述壳体主体包括入口口部和出口口部，待过滤的水流过所述入口口部，已过滤的水流过所述出口口部；-盖装置，包括帽构件和操作构件，所述帽构件能插入到所述入口开口中，从而密封地接合所述开口边缘；ii)过滤器组，适于容纳在所述过滤室中，将所述过滤室分成脏区域和清洁区域，其中，所述过滤器组包括过滤介质和联接到所述过滤介质的过滤器结构，所述过滤器结构包括封头板；其中，所述帽构件具有贯通开口，并且所述封头板包括定心元件；其中，所述操作构件能穿过所述贯通开口与所述定心元件接合，其中，所述操作构件接合所述帽构件并且使所述封头板与所述帽构件密封接合。
本文所述的洗衣机包括洗衣机滚筒和洗衣机管道，所述洗衣机管道优选地用于排放和/或再循环滚筒的水，所述洗衣机还包括根据前述的过滤器组件，所述过滤器组件流体地连接到所述洗衣机管道。
