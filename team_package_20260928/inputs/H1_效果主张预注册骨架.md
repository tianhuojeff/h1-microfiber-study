# H1 效果主张预注册骨架

更新：2026-09-21。性质：文献和公开技术文本研究后的比较规则，不是实验方案执行记录；没有实验数据、阈值、样本量、仪器能力或结论。

## 适用比较

比较固定过滤主体、来水、清理触发条件、运行终点和终端采样方法下的 C1（再生浓缩流至开放受控容器）与 C2（同一再生浓缩流至可拆收集端）；C0 只用作不做运行中再生的拆解回收参照。四个流路量 `M_pass`、`M_solid`、`M_waste`、`ΔM_inventory` 和未解释差额 `ε` 的定义及互斥关系，以《H1 候选技术差异与淘汰条件》和《测量链计算口径与放行条件》为准。

对每一项再加最终去向标签：`C` 受控留存，`D` 有证据进入排水，`A` 意外逸散，`U` 未知。只有有证据的 `D+A` 才可在本试验边界内称为 `M_discharge`；`C` 与 `U` 都不能静默写成零。

## 允许判定的问题

|编号|预先问题|主要比较量|可支持的表述|不能支持的表述|
|---|---|---|---|---|
|H1-A|C2 是否让更多目标物以已取出固体离开本次系统边界？|按同一材料/尺寸范围估计的 `M_solid/M_in`，并附期末存量与 `ε`|“在本次已记录条件和计量边界内，C2 的已取出固体比例高于/不高于 C1”|“可拆收集端天然能消除排放”|
|H1-B|C2 是否减少有证据的失控排水或逸散？|`M_discharge/M_in`，以及各 `D/A/U` 明细|“在本次边界内，有证据的 D+A 低于/不低于 C1”|“减少自然环境污染”或“已完成最终处置”|
|H1-C|C2 是否不损害、或改善再生后的水力恢复？|共同测试点的压差或流量恢复、首次再运行释放、旁通/溢流记录|“在预先固定的水力测量条件下，恢复表现满足/不满足比较规则”|“长期家庭寿命已验证”|
|H1-D|收集端是否只改变物料形态或记账位置？|C1/C2 中液相、固相、存量与去向的全部互斥分配|“差异主要表现为含水率、储运/处置接口或操作负担，而非已证实 D+A 变化”|把同一受控浓缩液改记为固体后称为净减排|

## 比较资格与判定顺序

1. **资格先于效果。** `measurement_ready` 必须为真：测量对象、匹配空白、回收适用范围、分样代表性、流路、关联不确定度、独立重复和预定精度规则均已冻结并经预试验核验。当前仍为 `false`。
2. **先报告原始观测，再报告校正估计。** 已知输入、总残渣、目标材料质量和计数不能互相替代；回收校正只在本次匹配验证允许时采用。
3. **先看闭合，再看条件差异。** `ε` 必须与其不确定度、未知去向和期末存量同时列示。闭合区间含零不等于没有未测损失。
4. **判定不确定也要保留。** 预定实用差异、区间方法和覆盖率尚未冻结时，只能写“未判定”；不得用单轮最好结果替代 C1/C2 比较。
5. **真实洗衣废水另起验证。** 标准纤维通过不自动支持真实衣物、洗涤剂、毛发和颗粒共存时的结论；真实来水须材质鉴别与空白证据。

## 已被排除的结构性结论

公开技术文本已经提供滤芯抽出/维护（CN118273060A）、封闭可移出过滤物容器（CN112914464A）、清理后排污和下游二次回收（CN115700309A）以及微粒二次流到可拆收集腔（WO2023047385A1）的技术路径。因此本研究不以“增加收集盒”“可拆”“二次流”“再生”本身作为效果或结论；它们只决定应测的流路和失效模式。
