# H1 最小验证方案方法学复核（只读审查）

审查范围：`最小验证方案_研究草案.md`、`研究问题与证据矩阵.md`、L07、L12（Browne 2020 全文核验卡）与 L13。本文不构成实验方案批准、样本量结论、硬件安全限值或实物实验记录。

## 结论先行

草案已经正确提出物料衡算、两套分母、维护废液和真实混合来水的分阶段框架，且没有把 L07 的标准纤维、L12 的短期洗衣对照或 L13 的成熟慢砂结果混作同一装置结论。当前仍不能单凭 B/C 阶段的流路质量差异识别“收集端带来的装置效果”：进水批次、衣物脱落、运行顺序、滤芯状态和测量回收都可能造成同方向差异。必须先固定主效应、终点去向、随机化和可接受的测量链表现，才可解释组间差异。

## 1. 先把待识别的效应写成可测问题

### 当前缺口

- B 阶段的“无再生、浓缩废流全部收集、浓缩流接可取出收集端”虽有对照，但尚未规定每次比较使用同一批、同质化后的来水，还是不同衣物／不同洗次的来水。后者会把衣物脱落差异误归给装置。
- C1（浓缩废流完整收进容器）本身也可能是受控收集；C2 把液态浓缩流变为固体，或提高 `M_solid`，并不能自动解释为更少环境排放。
- 草案把 `M_waste` 称为“排出”，容易使维护液或浓缩液被误读为已排入环境。它首先是一个维护／浓缩物流，不等于环境逸散。

### 修正建议

1. 在记录表首行固定主估计量。例如：在相同输入、相同过滤主体、相同累计处理量和相同终点去向下，比较各组**进入排水逸散端的目标纤维量／实际进入量**；把“收集端可拆取性”和“液转固”列为次要操作结果。
2. 给每一份物料增加终点去向字段：`受控收集待处置`、`已排水逸散`、`已确认其他逸散`、`装置内存量`、`未知`。只有已排水逸散端及已确认其他逸散端的互斥总和可以称为已测环境排放；未知单列，绝不并入减排。
3. C1 与 C2 必须在同一处置边界比较：若 C1 的整瓶浓缩液也被密闭、称量并受控留存，主终点可能相同；C2 能否改善的是取出便利性、含水状态、操作滴漏和维护时间，须另测而不能由 `M_solid` 的增加替代。
4. 主机理阶段使用同一均质、可追溯的标准纤维进水，记录实际进入量；真实衣物阶段从**同一次洗涤、充分混匀的废水**分取到各装置组，或把同一衣物组合设为区组／配对单位。不同洗次、不同衣物包或不同累计磨损阶段不得直接当作装置组差异。

## 2. 重复、随机化与状态控制

### 当前缺口

- 草案写有“重复性”，但未界定独立重复是独立进水制备、独立洗次、独立滤芯／装置运行，还是同一份样品的重复显微计数。后者只能估计读数误差，不能证明装置效果稳定。
- 未规定组别、滤芯、来水批次和操作日的分配顺序。若 C2 总在后期运行，滤芯熟化、残留或衣物衰减会与组别完全混杂。
- 未规定同一过滤主体复用时的期初状态、终端拆解回收和交叉污染处理。

### 修正建议

- 在方案中分列并如实报告三种层次：`独立运行重复`、`同一均质进水的分样／技术重复`、`同一样品的计数或鉴别重复`；统计或图表不得把后两者冒充独立装置重复。
- 在开始前生成并保存组别运行顺序。至少按来水批次／衣物批次、操作日和滤芯或装置编号分区组，再在每个区组内随机分配 C1/C2 与基线；记录实际偏离随机顺序的原因。
- 如因设备数量只能串行运行，采用预先定义的交叉或区组顺序，并在每次切换后做终端回收和空白冲洗；无法消除 carryover 时，该运行只能作探索性观察，不能承担主比较。
- 每轮固定并记录：累计处理体积、目标流量的实测值、压差、滤芯／床层初始状态、距上次清理的循环数、清理动作和来水批次。比较应在共同体积或共同的预设状态点进行，而不是由某组先堵塞或先终止来决定比较时点。

## 3. 空白、回收率、分母与检测能力

### 空白的具体缺口与修正

草案已有流程空白，却没有覆盖纤维污染和多流路转移的来源。每个分析批次应至少分开记录：

|空白／核对项|回答的误差来源|记录要求|
|---|---|---|
|试剂与滤膜空白|消解、分离、过滤和滤膜背景|与样品同批处理，保留材质、数量／质量、尺寸信息|
|管路／装置运行空白|进水、管壁、密封件与清理动作带入或释出|走完整流路及清理步骤，不以未接触装置的水代替|
|现场／空气暴露空白|开口取样、拆卸和显微操作的空气纤维|与实际操作同时暴露并记录暴露时间和位置|
|空白洗次或基质空白|机器、洗涤剂和来水本底|真实衣物阶段单列，不能用标准纤维水样空白替代|
|端到端加标回收|纤维在进样、过滤、清理、消解和鉴别中的总损失|按拟报告的材质与长度／尺寸组分别加标，覆盖各流路和维护水|

### 回收率和分母的具体缺口与修正

- `M_in` 必须保留“投加量”“上游未进入量”和“实际进入量”的原始记录；标准纤维以实际进入量为主分母。真实废水不能假装存在已知输入质量，应报告抽样估计法、不确定度和是否采用质量、数量或二者。
- 每个物料项同时保留纤维**数量、经材质鉴别的质量（若可得）、非目标残渣质量及湿重**；不能以湿棉絮、总干渣或未鉴别颗粒填补微塑料质量。
- 每个流路的原始量、空白量、空白校正后量、加标回收率和是否低于定量能力应同表保存。负校正值、回收率 >100%、未识别纤维及 `ε` 均保留原值和旗标；不截断。
- L07 的回收率限制说明“高截留比例”不能覆盖低或不稳定的总回收。故主报告须同时显示：输入分母比例、已回收分配比例、总回收率／物料闭合与未知去向，而非只报一个百分比。

### 检测限／定量能力的具体缺口与修正

- 方案未定义检测限、方法空白波动、材质鉴别阈值、长度／尺寸可见范围及质量称量下限。L13 的约 7 μm 光学分辨率和“未检出 <10 μm”的限制说明，未检出不是零排放。
- A 阶段应依据实际空白、加标和重复读数建立各指标的报告限／定量限及其适用材质和尺寸范围，并在进入 B 前锁定；没有可区分样品信号与空白、或无可接受端到端回收表现时，不进入效应比较。这里不预设无来源的数值阈值。

## 4. 停止条件、无效运行与结果解释

### 当前缺口

C 阶段提到“预注册循环上限或失败条件”，但没有把停止、可重新运行和不可解释数据分开；也未定义哪些差额会使一次运行不能用于主结论。

### 修正建议

在 A 阶段结果出来后、B/C 开始前，将下列项目写入版本冻结的记录表：

1. 共同终点（累计体积／循环或预先选定状态点）与每组相同的停止规则；
2. 流量或压差无法维持目标工况、未记录旁通／泄漏、清理液未全量收集、空白污染使信号不可区分、或物料闭合无法解释时的处理规则；
3. 区分“为保护设备或人员而停止”“测量链无效”“装置性能失败”“可在完整清洁和新进水后重做”的代码。硬件安全界限必须另以目标设备已核规格制定，本复核不填数值；
4. 停止后仍做终端拆解、残留和清洗水回收，记录停止原因。不能删去失败循环或把终止前的最佳一轮替代完整结果。

## 5. 比较与推断的边界

- 主比较应呈现每个独立运行及区组信息、效应方向和不确定性，并同步报告物料闭合、空白与回收。即使差异不显著，也不能据此说“没有装置效果”。
- 若要使用“等效”或“非劣”表述，必须在试验前给出与实际决策相关、可说明来源的效应界限，并按该界限设计和解释；当前资料既未给出界限也未给出样本量依据，因此仅能报告估计差异与不确定性，不能把未显著转换成等效。
- 不为本方案设定独立重复数或样本量结论。A 阶段的空白、回收、变异和可执行性数据只能用于形成下一版有依据的设计，不倒填为已经证明的精度。
- L12 的短期“有／无滤器”结果可提示真实衣物、孔径和聚合物均会影响排水，但其摘要／正文／补表存在需保留的定量不一致，也没有维护闭环；不能作为本装置组的预期效应值。L13 的慢砂去除率亦不能移作即时洗衣排水或再生端的性能目标。

## 进入实施前的最小修订清单

1. 固定主终点和每一物流的终点去向；将 `M_waste` 改为维护／浓缩物流，并单列真实排水逸散与未知。
2. 明确 B 的同批均质进水、D 的同洗次分样／衣物区组策略，写出独立重复的定义。
3. 固定区组与随机顺序、复用装置的清洁回收步骤和状态记录。
4. 配置上述空白与端到端加标回收，随后基于 A 的真实数据锁定报告限、定量能力和无效运行规则。
5. 预先登记共同终点、停止／重做／无效代码、终端回收与全量报告方式；不把未显著差异写成无效或等效。
