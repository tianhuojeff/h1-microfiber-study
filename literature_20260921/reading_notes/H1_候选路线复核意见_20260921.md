# H1 候选路线复核意见（2026-09-21）

范围：复核《候选路线与下一轮研究顺序》《H1_候选技术差异与淘汰条件》《H1_设计依据与现有技术对照》。本意见只调整研究问题优先级，不改写原卡、不作新颖性判断、不建议采购或开展实验。

## 结论：主排序保留，但收紧三处

优先问题仍应是：**同一过滤主体下，浓缩清理流进入受控收集端后，是否在共同触发条件下改善可控物料去向和水力恢复。**先做流路/计量链，再做重复循环；真实混合来水仍排在标准纤维计量链之后。理由未变：L07 已能分开浓缩、透过、滤元残留，却没有闭合实际家庭维护和终端处置；L05 显示截留随累积提高但会堵塞，未报告清理后恢复；L02/L14 只提供有限家庭行为边界。

三项应立即收紧：

## 建议的下一轮问题顺序

1. **流路与去向先行。** 在同一滤器、同一投加和共同清理触发下，互斥测量 `M_pass`、`M_solid`、`M_waste`、`ΔM_inventory` 与差额，并给每支路 C/D/A/U 标签。只有 `D+A` 可称已证实排水/逸散端；C1/C2 都是受控收集时，比较含水率、操作负担、残留与水力恢复，而非液转固后的表观“减排”。这是现有决策表已经确立、且新资料未削弱的首要未知项。依据：`H1_候选技术差异与淘汰条件.md`，候选边界与问题1—2。
2. **清理恢复而非寿命承诺。** 固定触发条件后，问清理前后相同流量下压差、相同压差下流量、首轮再运行逃逸和残留累积是否变化；旁通/故障流亦须计入。L07 与 L05 均提示“已清理/高截留”不等于恢复或寿命。依据：`L07_自清理机制与寿命证据.md`；`20260921_L04-L05-L09-L11_核验补充.md`，L05 PDF pp.5—8。
3. **再决定材料和几何。** L09/F02 表明材料和孔径不能用单一效率排序；F06 肋结构还没有微纤维质量证据。因此网孔、肋、入口/角度或脱水动作只能在前两项可解释后作为受控变量，不能预设“最优”或以 TRIZ 概念替代结果。依据：`20260921_L04-L05-L09-L11_核验补充.md`，L09 PDF pp.5、12—13；`F02_精读卡.md`，PDF pp.1、10—11；F06 短卡。
4. **最后才真实混合来水与家庭外推。** L02 的社区出水前后变化不等于单机截留；L14 的 43 人流失也不是不清滤器率。真实来水和用户端问题应分别量材质/空白/回收、逐步操作完成率、清理液与终端去向。依据：`H1_家庭维护证据与外推边界.md`：L02 PDF pp.3—7、L14 PDF pp.4—5、12、14。

## 不需要因新资料改变的判断

- “可拆收集端”仍可作为 C1/C2 对照，但只能检验受控收集、含水率、残留、滴漏、操作和恢复；WO2024199585A1、WO2021116933A1、WO2022084677A1 已披露容器收集/取出、压实排出、外置收集腔与移渣等路径，不能将其本身列作差异化结论。见 `H1_设计依据与现有技术对照.md`，WO 定位为 PDF pp.14—15、19—22、26—27、59—60。
- “压实/脱水”不升序：它只能在收集端和水力恢复已可解释后，作为有/无受控脱水的独立变量；须测压出液去向，不能由更干的固体推断环境收益。见 `H1_候选技术差异与淘汰条件.md` 问题6。

## 供总控验收的具体未知项

1. 同一清理触发下，C2 是否对预先定义主效果产生超过测量不确定度的改善，而非仅改变物料记账位置？
2. 清理后滤面/支撑区残留与压差/流量恢复是否同步；是否出现更早旁通？
3. 浓缩液、冲洗液、滴漏和故障流的 C/D/A/U 去向是否完整，尤其是否存在未记录的 D/A？
4. 在上述三项得到可解释结果前，肋结构、压力脉冲、慢砂和压实均没有足够本地证据进入“优先方案”层级。
