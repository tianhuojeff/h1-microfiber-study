# H1流路与终点示意

以下是待验证方案的计量图，没有实验结果。

```mermaid
flowchart TD
 A[实际进入的目标纤维] --> B[同一主滤器]
 B --> P[透过水与旁通]
 B --> R[再生浓缩流]
 B --> I[结束时滤面与管路存量]
 R --> C1[C1 全量收集容器]
 R --> C2[C2 可取出收集端]
 C2 --> S[取出固体]
 C2 --> L[收集端下游液体]
 C1 --> T[分别核验每一终端去向]
 S --> T
 L --> T
 P --> T
 T --> D[受控收集]
 T --> E[有证据进入排水或逸散]
 T --> U[去向未知 单列]
```

C1与C2是不同试验条件，不是在同一次试验中重复计算同一浓缩流。上游浓缩样仅用于过程核对；如果其最终固体和液体已经进入衡算，不再加一次浓缩总量。

质量账：实际输入＝互斥终端移出＋期末存量－期初存量＋未解释差额。

排水/逸散账与质量账分开：受控留存、液转固和最终环境减排是三件不同的事。期末存量的破坏性分析回收也不属于运行期装置固体移出成绩。
