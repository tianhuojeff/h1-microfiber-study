# 真实洗衣废水复验放行链

更新：2026-09-21。性质：由 F07 与 F08 的全文核验反推的研究放行规则；未开展真实洗衣试验，未给出样本量、检出限、仪器配置或效果结论。

## 前提

真实洗衣废水阶段不是 C1/C2 的起点。只有标准纤维阶段已经取得 `measurement_ready=true`，并能说明空白、加标回收、流路互斥、期末存量和不确定度时，才进入本阶段。标准纤维通过也只证明相应材料/尺寸/基质下的计量链，不自动外推到混合衣物、洗涤剂、天然纤维、毛发和颗粒共存的废水。

## 三条不能混用的报告链

|报告链|应保存的原始对象|可以回答|不能替代|
|---|---|---|---|
|全流路残渣质量|主洗、漂洗、washout、容器冲洗和维护液各自的全量或经说明的代表性分样|某收集孔径和处理链下的干残渣质量分配|目标聚合物质量或纤维根数|
|材质鉴别计数|预先定义抽样框、可分析纤维、未分类项、micro-FTIR/等效确认结果|在该鉴别子样中的材质、尺寸和计数构成|整条流路的聚合物质量|
|选择性处理后的目标质量|经过目标材质/尺寸/真实基质加标验证的分离或消解输出|所定义对象的目标质量估计|未经该基质验证的全流程回收或其他尺寸范围|

F08 的全流路干残渣、中心局部胶带取样鉴别和选择性消解后残渣来自不同分样与处理链；F07 的洗衣废水识别链与其面部磨砂 PE 加标回收也不是同一基质。H1 的数据表必须把三条链分开，禁止用识别比例乘总残渣质量，或把一个基质的回收率套到另一个基质。

## 放行顺序

1. **材料污染控制。** 记录容器/工具材质、器皿清洁、样品覆盖、操作衣物、每类空白和各空白的原始数值。F07 的玻璃器皿、铝箔覆盖和空白扣除可作为动作参考；它没有可借用的空白数值。
2. **洗机与流路背景。** 单列空机、流程、空气暴露与相邻洗次 washout；不能把“已清洗机器”或文献中的空机说明当成本机背景合格证据。F08 的完整 washout 收集说明该段必须独立记量。
3. **真实基质的加标适用性。** 按实际目标材质/尺寸组，在真实洗衣废水或经证明等效的基质中验证质量回收、计数回收和进入鉴别子样的比例。不得使用 F07 面部磨砂 PE 的约94.1%作为洗衣微纤维回收率。
4. **全量与分样设计。** 每项记录 `whole_stream` 或 `aliquot`、混匀证据、有效比例和体积；流路随时间变化、沉降或团聚时，体积分样比例不自动代表全流路。
5. **C1/C2 正式比较。** 仅在上述链闭合且主指标/不确定度/实用差异已冻结后，比较 H1 效果主张预注册骨架中的 H1-A—H1-D；所有旁通、滴漏、冲洗和未知去向继续以 C/D/A/U 单列。

## 拒绝外推的触发条件

- 未做真实基质加标，或回收不适用于目标材质、尺寸或本次处理链。
- 空白只写“已扣除”而没有原始数量、批次与校正关系。
- 用局部识别比例推算全量目标质量，却没有代表性抽样依据。
- 主洗、漂洗、washout、维护液、拆卸滴漏或期末存量有任何一条未记量。
- 只有标准纤维结果、只有总残渣质量，或只有显微图像，却主张真实家庭微塑料去除/减排。
