# H1 测量链计算口径与放行条件

2026-09-21。性质：研究方案补充，尚无实验数据。这里解决现有空白模板中“测得分样质量还是全流路质量”“回收校正是否使用”“误差是否相关”三个尚未明确的计算问题，不指定仪器、采购、实验样本数或装置性能。

## 1. 每个报告量先锁定测量对象

同一流路分别保存总干残渣质量、经验证的目标材料质量、可识别纤维计数。不能用显微鉴别的根数比例乘总残渣质量，直接得到聚合物质量：大、小纤维的单根质量不同，非纤维残渣也可能占重。

`raw_target_mass_mg` 必须注明 `aliquot`（本次取样部分）或 `whole_stream`（整个流路）。如果已经是全流路估计，再除一次取样比例会重复放大。原始称量差、空白差和全量估计应放在不同字段中。

## 2. 分样外推只计算一次

定义：代表性分样的净称量差为 `a`，按同样处理范围匹配的空白净差为 `b`；`f` 为该分样占全流路的有效比例，须有混匀和取样代表性证据，且 `0 < f <= 1`。

不做回收校正时，全流路空白校正估计为：

`M_blank = (a - b) / f`

本式中的 `a` 与 `b` 均为同一分样尺度、同单位、同处理链输出的净质量。全流路空白、单位体积空白、仅某一步骤的空气空白不能直接代入 `b`；须先记录各自基准和换算依据。回收校正式还要求“输出差值对应的目标信号”适用同一 `r`；若背景在回收步骤之后引入或空白经历不同处理链，须分开建立背景与样品的模型，不能默认背景也除以样品回收率。

若使用体积分样，`f = V_sample / V_stream` 仅在该时刻分样能代表全流路浓度时成立。连续来水浓度变化、纤维沉降、团聚或分层不能靠体积比例自动解决。多个独立分样用于估计同一流路时，应依据实际取样设计合并估计，不能把每个已外推全量直接相加。

只有方法已验证允许回收校正、且材质、尺寸和基质适用时，另报告：

`M_recovery_adjusted = (a - b) / (f * r)`

其中 `r` 是匹配测量链的回收比例，不是装置截留效率。保留未校正和校正值及校正理由；不能拿论文平均回收率替代本批测量验证，不能把全流程回收率对同一结果重复使用。`r` 未测、为零或不适用于本样品时，该校正结果留空。

负空白校正值、回收率大于 1 和未检出状态保留，不通过截断制造物料闭合。可计算的带符号估计不代表真实存在负质量；解释和报告限另行给出。

## 3. 共享空白会使流路估计相关

对上述回收校正模型，灵敏度系数为：

|输入|灵敏度|
|---|---|
|a|1/(f r)|
|b|-1/(f r)|
|f|-(a-b)/(f² r)|
|r|-(a-b)/(f r²)|

将这些系数组成向量 `g`，用输入的协方差矩阵 `Σ` 计算一阶近似 `u²(M) = gᵀΣg`。一般传播式及其一阶近似条件依据 [NIST TN 1297 Appendix A, A.1–A.3](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)。本表及下列 H1 应用是对测量模型的推导，不是 NIST 对本装置的验证。

例如两个终端共用同一空白均值 `b`，其校正估计会共享该空白的不确定度。不能把同一个空白当成两次互不相关的误差；同一校准、同一投加量也应记录关联。缺少协方差依据时标记为待评估，不能默认填零。接近零、比值高度非线性或输入分布不适用时，不以一阶近似结果冒充已验证的区间。

## 4. 闭合差与回收率分开解释

沿用既有互斥终端规则：

`ε = M_in - Σ M_terminal - (M_final_inventory - M_initial_inventory)`

主闭合式须统一材料/尺寸范围和所估计的真实量。每项用能估计该目标量的已验证方法：直接称得的已知输入不必人为除以终端分析回收率；通过分离/鉴别测得的终端或存量则须说明相应校正。原始观测闭合、空白校正观测闭合和经验证的目标量估计闭合可以并列，但不得把不同层级项随意拼接并标为同一闭合结果。尚无适用回收证据时，只报告能支持的观测口径及缺口，不伪造完整目标量闭合。

分别保存 `ε`、`ε/M_in` 和相应不确定度；输入为零或无法定量时，不计算以输入为分母的比率。用于期末存量测定的拆解冲洗只进入存量项，不再进入日常维护移出量。

闭合区间包含零只表示观测与零差额相容，并不能证明没有未测损失；很宽的不确定度也可能使其包含零。因此放行还需预先给出与研究目标相容的精度要求，不能仅靠“差额不显著”放行。该要求须在测量预试验后、C1/C2 比较前冻结，当前保持未定。

两个条件比较 `Δ = M_C2 - M_C1` 时，明确是否同一批来水配对，以及共享空白、校准和输入估计。差值方向、独立运行间变异、测量不确定度、预定实用差异分别报告；重复称同一张膜不增加独立装置运行次数。

`ε` 和 `Δ` 也各自是联合原始输入的函数，应分别求其完整梯度并用对应的联合协方差矩阵传播，不能先计算各流路 `u(M)` 后无条件按独立平方和合并。尤其同一空白或回收估计既用于输入又用于输出时，其影响可能部分抵消或叠加。无法估计重要关联、又没有预先论证的保守边界时，区间及基于该区间的判定均标为未定。

## 5. 放行记录

|阶段|必须已有的证据|不能替代它的内容|
|---|---|---|
|报告量定义|材料/尺寸范围、计数或质量、分样或全流路|网孔和膜孔径|
|测量链预试验|匹配空白、分样代表性、回收及变异、实际报告能力|文献仪器读数或文献平均回收率|
|流路闭合|互斥终端、取样移出、期初/期末存量、未知去向|把未知填零或多次累计上游/下游量|
|条件比较|独立单位、配对/区组、共同终点、主效果、预定精度与实用差异|最好一轮的效率或单个显著性结果|

当前未具备实际空白、仪器能力及回收数据，因此不能填入数值检出限、放行阈值和样本数；论文研究与测量链设计仍可继续。L08 全文获取受阻与这些工作并无必然依赖。

放行分为两次，防止把“允许做比较”混同“已经证明装置更好”：

1. **进入比较的测量资格**：先冻结测量对象、匹配空白/回收适用范围、区间构造及覆盖率、精度/闭合准则、独立重复与取样设计、低于报告能力和缺失数据的处理规则。仅当各必填项已确定且预试验满足冻结准则时，`measurement_ready=true`；任一关键项未知或不满足则为 `false`，不能因单个闭合区间含零而放行。
2. **比较后的效果判定**：在查看 C1/C2 对比结果前，固定主指标、改善方向、实用差异 `δ*`、区间方法及覆盖率，以及检验优越、等效还是非劣。若选择“改善超过实用差异”的优越命题，并把改善定义为正值，则仅在数据有效、预定精度准则满足且改善区间下界大于 `δ*` 时记为支持。区间跨越该界记为不确定；整体位于界下则不支持该命题，不能改换命题补救。等效或非劣须另行预定对应界限与判断式，不能沿用这条优越规则。

当前上述待定项仍为空，因此 `measurement_ready=false`，`effect_claim=not_evaluated`。这只约束进入实验比较与作出效果主张，不阻止继续文献研究。
