# H1 P0 测量资格放行判定表

更新：2026-09-28。性质：把既有 P0 方案中的资格条件转成一次预试验结束后可逐格签核的执行表。它不记录实验数据、不填数值阈值、不设置样本量，也不使 `measurement_ready` 改变为 true。

## 为什么新增此表

现有《H1 判定资格证据审计》列出七类缺口，《测量链计算口径与放行条件》规定公式和两阶段放行，《空白终端流路记录》提供逐条记录字段；但三者之间还缺少一个**单一、不可跳项的 P0 判定面**。本表只补这个接口：把每个放行项绑定到所需原始记录、冻结文件和唯一状态，防止把“模板已存在”“公式可用”或“某一结果看起来闭合”误判为可进入 C1/C2。

本表基于已核的 H1 本地研究材料；其要求来源于这些材料的边界，而非借用任何文献数值：

- 资格项与当前未具备状态：[H1 判定资格证据审计](../reading_notes/H1_判定资格证据审计.md)。
- 估计层级、共享空白／回收率、闭合和不确定度规则：[测量链计算口径与放行条件](测量链计算口径与放行条件.md)。
- 字段名称与终端互斥规则：[记录字段与计量边界](记录字段与计量边界.md)、[P0-r1 空记录](空白终端流路记录.json)。
- 后续 C1/C2 问题和主张边界：[H1 效果主张预注册骨架](H1_效果主张预注册骨架.md)。

## 使用时点与状态词

1. **冻结前**：所有 G 项均为 `UNSET`；只能补方案或开展 P0 预试验，不能进行 C1/C2 效果比较。
2. **预试验记录完成后、查看任何 C1/C2 比较数据前**：由记录保管者逐项写入 `PASS`、`FAIL` 或 `UNRESOLVED`，并列出证据文件与行／记录 ID。`N/A` 不适用于 G01—G08 的任何关键项。
3. **放行**：仅当 G01—G08 全为 `PASS`，且“冻结包”已建立完整哈希、冻结时间早于第一份 C1/C2 比较记录，才可写 `measurement_ready=true`。这只允许进入比较，并不支持效果结论。
4. **不放行**：任一项为 `FAIL`、`UNRESOLVED` 或 `UNSET`，即为 `measurement_ready=false`。应保留原始预试验记录，写明缺口；不得以删去异常、重命名流路或改换主指标补救。

## 决策记录最小格式

每次判定生成一个单独的只追加记录，至少含下列字段；空模板不能替代本记录。

```text
p0_gate_record_id:
assessment_time:
assessor:
pretest_run_ids:
freeze_bundle_paths_and_sha256:
first_c1_c2_comparison_record_time: null | ISO-8601
G01: PASS | FAIL | UNRESOLVED | UNSET; evidence_ids; reason
...
G08: PASS | FAIL | UNRESOLVED | UNSET; evidence_ids; reason
measurement_ready: true | false
next_action: enter_c1_c2 | repair_p0_chain | stop_or_redesign
effect_claim_allowed: false
```

`measurement_ready=true` 的有效性还要求 `first_c1_c2_comparison_record_time` 为 `null`，或者晚于 `assessment_time` 与冻结包时间；否则该次资格判定受“看见结果后再定规则”的污染，结论只能是 `UNRESOLVED`，需以新的独立预试验链重建。

## P0 后的边界

即使八项全部通过，下一步也只能按已冻结的 C1/C2 方案记录比较数据。任何比较后的状态都保持 `effect_claim_allowed=false`，直到另行满足《H1 效果主张预注册骨架》中的主指标、方向、实用差异、区间方法和数据有效性规则。真实洗衣废水还须走《真实洗衣废水复验放行链》；标准纤维 P0 放行不跨越这一关。

```text
G01—G08 = UNSET
measurement_ready = false
effect_claim_allowed = false
```
